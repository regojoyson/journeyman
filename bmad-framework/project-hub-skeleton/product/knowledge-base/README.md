# Product Knowledge Base

Discovery inputs for the **Product** track. Refreshed by feeder jobs (or dropped in by
the team); read by the **Analyst** and product discovery agents.

| Folder / file | Holds |
|---|---|
| `analytics/` | usage/funnel exports, dashboards-as-data |
| `customer-feedback/` | reviews, NPS, interview notes |
| `competitors/` | competitor teardowns, feature matrices |
| `support-tickets/` | recurring issues, pain themes |
| `rfps/` | RFP / RFQ documents |
| `market-trends.md` | market signals, trend notes |

Keep entries dated and sourced so agents can cite them in discovery output.
