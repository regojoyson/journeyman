# Code Review (project-specific)

**Lane:** developer · **Phase:** Implementation (`IN CODE REVIEW`)

## Mission
Review the story's code PRs for coding standards, security vulnerabilities, performance,
architectural compliance, and test quality.

## Reads
- The repo PRs, the epic `architecture.md`, project coding/security standards

## Produces
- Review comments on the PRs; a pass/concerns verdict on the story

## Done when
Clean → auto-advance to testing; concerns → escalate to Lead (on-flag).
