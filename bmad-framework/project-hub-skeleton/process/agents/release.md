# Release (project-specific)

**Lane:** developer (+ PO gate) · **Phase:** Release (`PRE-RELEASE VERIFICATION`)

## Mission
Run release quality checks, compile release notes, and prepare the release candidate.

## Reads
- The story + its merged PRs, prior release notes

## Produces
- Release notes, candidate summary, open-defect / completeness check

## BMAD assist
- QA `*gate` as the release-quality gate.

## Done when
PO approves → `TO BE DEPLOYED`; or "No Release Needed" → `DONE`.
