# EPIC-template

Copy this folder to start a new epic. Rename it `EPIC-<your-slug>` and fill the files.

```
EPIC-<slug>/
├── epic.md              # the epic (frontmatter + problem/value/scope) — Discovery
├── ux/design-spec.md    # UX flows, wireframes, design spec — Design
├── architecture.md      # solution design: impact, API, DB, security — Solution
└── stories/             # one STORY-*.md per story — Grooming
```

Templates for each file live in [`../../process/templates/`](../../process/templates/).
See [`../../CONVENTIONS.md`](../../CONVENTIONS.md) for the required frontmatter.
