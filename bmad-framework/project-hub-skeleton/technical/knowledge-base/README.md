# Technical Knowledge Base

Discovery inputs for the **Technical** track. Refreshed by feeder jobs; read by the
**Architect** and tech discovery agents (code-quality, dependency, performance, test-quality).

| Folder | Holds |
|---|---|
| `static-analysis/` | linter / SAST / complexity reports |
| `dependencies/` | dependency manifests, outdated/vuln reports |
| `crash-reports/` | error tracker exports, crash clusters |
| `performance/` | perf metrics, profiling, load-test results |

Also relevant: source repos (see `repos/registry.yaml`), PR history, and CI/CD logs —
referenced rather than copied here.
