# YAML Autocomplete for pipeline.yaml and flow configs

**Date:** 2026-04-21
**Status:** Approved

## Goal

Enable VS Code autocomplete, inline validation, and field suggestions when editing `config/pipeline.yaml` and `config/flows/*.yaml`. The autocomplete is derived directly from the existing Zod schemas so it stays in sync with the runtime validation.

## Architecture

Three components:

1. **Schema generation script** — `packages/pipeline/src/generate-schemas.ts` converts the two Zod schemas to JSON Schema and writes them to `config/schemas/`.
2. **Committed schema files** — `config/schemas/pipeline.schema.json` and `config/schemas/flow.schema.json` are committed so autocomplete works immediately after clone.
3. **VS Code config** — `.vscode/settings.json` maps each schema to its YAML glob; `.vscode/extensions.json` recommends the YAML extension.

## Components

### `packages/pipeline/src/generate-schemas.ts`

Uses `zod-to-json-schema` to convert `PipelineConfigSchema` and `FlowSchema` to JSON Schema objects, then writes them synchronously to `config/schemas/pipeline.schema.json` and `config/schemas/flow.schema.json` (relative to the repo root, resolved from `process.cwd()`).

Each output file includes a `$comment` field:
```
"Auto-generated from packages/pipeline/src/config/*-schema.ts — run npm run generate:schemas to update"
```

### npm scripts

`packages/pipeline/package.json`:
```json
"generate:schemas": "tsx src/generate-schemas.ts"
```

Root `package.json`:
```json
"generate:schemas": "npm run generate:schemas -w packages/pipeline"
```

### `config/schemas/` (committed)

Two JSON Schema files generated by the script. Committed so contributors get autocomplete on clone without running the script. Re-run the script after changing `pipeline-schema.ts` or `flow-schema.ts`.

### `.vscode/settings.json`

```json
{
  "yaml.schemas": {
    "./config/schemas/pipeline.schema.json": ["config/pipeline.yaml"],
    "./config/schemas/flow.schema.json": ["config/flows/*.yaml"]
  }
}
```

### `.vscode/extensions.json`

```json
{
  "recommendations": ["redhat.vscode-yaml"]
}
```

## Data Flow

```
Zod schemas (pipeline-schema.ts, flow-schema.ts)
  → generate-schemas.ts (zod-to-json-schema)
  → config/schemas/*.json  (committed)
  → .vscode/settings.json  (yaml.schemas mapping)
  → VS Code YAML extension  (autocomplete + validation in editor)
```

## Dependencies

- `zod-to-json-schema` added to `packages/pipeline` devDependencies.
- `redhat.vscode-yaml` VS Code extension (recommended, not required).

## Out of Scope

- CI enforcement of schema freshness (kept simple — developer convention).
- Inline `yaml-language-server` comments in YAML files.
- Support for editors other than VS Code.
